# Spring Boot Journal App

A backend journal application built while learning Spring Boot and MongoDB.

## Tech Stack
- Java
- Spring Boot
- MongoDB
- Maven
- Spring Security

## Features
- User APIs
- Journal entry CRUD APIs
- Authentication & authorization
- RESTful APIs

## Run Locally

Set environment variable:

MONGO_URI=your_mongodb_connection_string

Then run:

./mvnw spring-boot:run
